## What I am working on

Claimline Data Toolkit is an open source project I maintain. It validates healthcare claims data with a set of written rules, flags duplicate and malformed lines, and reconciles claim totals against remittance lines within a small tolerance. The sample data is synthetic and generated with known defects planted in it, so anyone can run the batch job and see exactly what the rules catch. The code and rule catalogue live at https://github.com/alijsyed0717/claimline-data-toolkit
